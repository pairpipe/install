# macOS notes

- Supported: macOS 13+, Apple Silicon (arm64) and Intel (amd64). pairpipe picks the right program automatically.
- The default route needs no Git and no Homebrew.
- If the program is blocked ("developer cannot be verified"), see [issues/program-wont-run.md#blocked](../issues/program-wont-run.md#blocked).
- `claude` not found after install: add `~/.local/bin` to PATH ([prerequisites/claude-code.md](../prerequisites/claude-code.md#claude-not-found)).
